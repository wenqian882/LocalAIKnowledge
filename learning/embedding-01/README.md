# 第一次真实向量实验

只做一个实验：把三句非个人示例转成向量，比较哪两句更相似。此目录独立于 Electron 应用，不加载简历、聊天、个人知识库或旧索引，不启动数据库或服务，也不接入模型 API。

| 标签 | 固定输入 |
| --- | --- |
| A | 支持导出 Excel。 |
| B | 可以生成电子表格。 |
| C | 明天可能下雨。 |

先提出预期：A/B 应比 A/C、B/C 更相似。脚本保留实际结果，即使预期没有得到支持，也不会改数字或替换句子来凑结果。

2026-11-17 首次实测：A/B 为 0.607955，A/C 为 0.437700，B/C 为 0.411903，每句为512维向量。小数四舍五入展示，原始分数、向量前8维、模型快照/权重摘要和运行环境见 [result.json](result.json)。这是三句示例的结果，不是RAG准确率或模型整体质量评测；分数不是概率，也没有通用“超过某分就一定相关”的标准。

这一步用的是**余弦相似度**：将向量按长度归一化后计算内积。先观察相对顺序即可，无需现在背公式。脚本检查向量维度/有限数值、非零范数、自相似度、矩阵对称性和数值范围。

## 复现

使用已安装 [requirements.txt](requirements.txt) 中依赖的 Python 环境，并准备完整的本地 ONNX 模型目录（含模型、配置和 tokenizer 文件）。Python 环境与模型是这个可选实验的依赖，不是桌面应用的启动前提。

在本目录运行以下一条命令，其中模型路径需要替换为本机已有目录：

```powershell
python -X utf8 experiment.py --model-dir "D:/Models/bge-small-zh-v1.5"
```

`experiment.py` 只编码文件顶部的 `SENTENCES`，默认生成同目录的 `result.json`。`--output` 可以指定结果文件位置。脚本启用离线选项、指定本地模型路径，并通过 Python 审计钩子拒绝 socket 连接与DNS解析；模型不完整时停止，不自动下载。结果中的 `network_attempts` 是该脚本捕获的联网尝试次数，不是操作系统级抓包报告。

当前这台机器的首次实验复用了已有的 FastEmbed 环境和公开模型缓存，没有安装新包、复制模型权重或加载另一项目的业务模块/私人资料。可选依赖和模型均未打包进 Electron；应用当前仍只有字面关键词检索，尚未接入此脚本。
