# 当资料没有答案时，Top-1仍会返回什么

这一轮只增加一个无答案问题，不重跑此前的默认问题或桌面验收：

> 星灯工具支持多人权限管理吗？

事先审阅三份固定虚构资料，它们只讲导出格式、主题/字号和天气。没有多人权限的说明，所以预期回答口径为**“资料未说明，无法确认。”** 这个标签写在推理前的 [case.json](case.json) 中，是样例资料核对的标注，不是模型自动判定。

2026-11-17真实本机检索结果：

| 排名 | 返回资料 | 余弦相似度 |
| --- | --- | ---: |
| 1 | 导出说明 | 0.488349 |
| 2 | 界面设置 | 0.456563 |
| 3 | 周末天气 | 0.251965 |

原始结果见 [result.json](result.json)。第一名仍会被取出，但其原文不足以支持“支持权限管理”或“不支持权限管理”。本轮没有让回答模型实际生成回复，因此尚未验证真实模型是否会保留不确定性。

## 本轮只理解这一点

**排名第一，只是当前候选里向量最相近的一段，不保证有回答问题所需的证据。**

这个3段资料的小实验没有相似度阈值或可回答性判定，资料不为空时Top-1会取一段。不能根据本例直接设置“低于0.5就拒答”，更不能把0.488理解为48.8%的正确率；阈值和回答依据需要更多已核对的问题来检验。

## 复现

本轮仅给已有[检索脚本](../embedding-02/retrieve.py)增加 `--question` 参数，向量计算/排序与3份资料不变。使用之前已经安装依赖的Python环境，在项目根目录执行一条命令，替换本机模型目录：

```powershell
python -X utf8 learning/embedding-02/retrieve.py --model-dir "D:/Models/bge-small-zh-v1.5" --question "星灯工具支持多人权限管理吗？" --output learning/no-answer-04/result.json
```

`--output`另存结果，保留原始正例。结果的 `source_base` 是相对于项目根目录的资料目录，`source` 是相对于该目录的文件路径。自定义问题不沿用默认问题的预期第一名，`expected_top1_document` / `example_expectation_met` 为 `null`；无答案标注独立保存在case.json中。

本轮复用相同本机BGE缓存、CPU/2线程及查询指令，捕获联网尝试0，无下载/付费API/个人资料。只检查新问题输入、Top-1结果与来源、空白问题拒绝和新报告元数据，不重验旧功能；桌面应用仍为v0.7.0关键词检索。实现和运行由Codex完成，不代表学习者已独立实现或掌握拒答判断。
