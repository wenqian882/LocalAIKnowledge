# 用问题找资料：第一次 Top-1 检索

本轮只做一件事：把一个问题和三段固定的虚构资料向量化，比较相似度，取排名第一的资料块。没有读取用户文件、接入桌面、生成答案或建立持久化索引。

问题：**星灯工具能把结果导出成电子表格吗？**

候选资料事先固定，每个短文件作为一个块，不重跑旧分块功能：

- [导出结果](samples/export-guide.md)：支持导出 Excel、CSV、JSON。
- [界面设置](samples/appearance.md)：主题与字号。
- [周末天气](samples/weather.md)：多云与下雨。

预期支持问题的来源事先标为 `export-guide`，不根据模型输出改标签或样例。

## 2026-11-17 实测

| 排名 | 来源 | 余弦相似度 |
| --- | --- | ---: |
| 1 | 导出结果 | 0.705751 |
| 2 | 界面设置 | 0.525121 |
| 3 | 周末天气 | 0.280802 |

**Top-1 就是只取第一名；Top-k 就是取前 k 块。** 这里第一名恰好是事先标注的支持来源，只说明本例找到了预期块，不能推出整体检索准确率。分数不是回答正确率，也不是“必然相关”的概率。

第一名原文提到 Excel，但没有“电子表格”这个连续词。模型使用向量相似度得到了上述排序；不据这个小例子宣称向量检索一定优于关键词检索。

完整排名、原文、来源/块ID与位置、文件SHA256、模型快照/权重摘要和运行环境见 [result.json](result.json)。`selected` 是实际取出的块，`generated_answer` 为 `null`，表示本轮没有生成回答。

## 计算和复现

复用已有 FastEmbed 0.9.1 / BGE-small-zh-v1.5 ONNX 缓存，CPU 2线程。本轮问题与每段资料各得到512维向量，归一化后按余弦相似度降序排列。只在内存中比较3个块，不需要向量数据库。

按照 [BGE 模型卡](https://huggingface.co/BAAI/bge-small-zh-v1.5) 的短查询检索建议，**只给问题**添加“为这个句子生成表示以用于检索相关文章：”，资料按原文编码。实际输入写入结果。与上一轮不同的问题、资料及编码方式产生的分数不用于直接比较“提升”。

使用已安装[上一轮依赖](../embedding-01/requirements.txt)的Python解释器，在本目录运行以下一条命令，并替换模型目录：

```powershell
python -X utf8 retrieve.py --model-dir "D:/Models/bge-small-zh-v1.5" --top-k 1
```

模型目录须已包含完整ONNX、配置和tokenizer文件。只读取 `SOURCES` 明确列出的这三份示例；缺少模型时停止，不自动下载。离线参数及Python审计钩子拒绝socket连接/DNS解析，捕获的联网尝试为0；不是操作系统级抓包报告。

后续增加的 `--question` 可替换问题。修改问题时请同时用 `--output` 保存到另一个文件，保留原始结果；自定义问题不自动沿用原问题的预期来源。示例见[无答案问题实验](../no-answer-04/README.md)。

本轮独立验证问题/资料向量的维度、有限非零数值、相似度范围、完整降序排名、Top-1与来源原文/摘要对应，以及非法k拒绝执行。没有重跑上一轮短句实验或桌面旧功能，没有API费用或应用数据写入。

实现和运行由Codex完成。学习者亲手操作、修改和解释仍待确认。桌面应用仍为v0.7.0关键词检索；本实验尚未接入应用，也未实现完整RAG问答。
