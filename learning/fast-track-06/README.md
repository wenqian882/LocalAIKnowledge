# 快节奏实操：一次读数据、选资料、组装消息

本轮把三个相关知识放在一个可运行练习里，不再把同一条原则反复拆成多轮问答。仍按初学基础说明用途，不假定学习者已经会写全部代码。

## 亲手操作

1. 用文本编辑器打开本目录的 `practice.py`，将 `TOP_K = 2` 改为 `TOP_K = 3`，保存。
2. 双击项目根目录的 `运行RAG代码练习.cmd`，查看选中来源和拼好的模型输入。
3. 原来前2块是导出说明、界面设置；改为3后，天气资料也会加入。观察哪块对当前问题有用，哪块带来了无关内容。

已有Python即可，不需要安装第三方包、下载模型或启动服务。脚本使用自身路径定位项目，从任意工作目录启动都可读取上一轮固定示例的真实检索记录。

## 一起理解三个操作

- `json.loads(...)`：把JSON文件里的文字转换为Python数据。
- `report["ranking"][:TOP_K]`：从已排序的列表取前k项。
- `"\n\n".join(...)`：把这些资料块用空行连接，成为模型的参考资料。

输入固定为 `learning/embedding-02/result.json`。输出是忽略提交的 `test-results/fast-track/current-prompt.txt`；它只是可发送的消息，程序没有读取密钥、发送API请求或生成回答，也没有改变桌面应用。旧的向量/检索结果不会重算或覆盖。

Codex实际运行了默认 `TOP_K = 2`，程序选出导出说明和界面设置，并保存消息。学习者修改为3、亲手运行及理解仍待反馈；这一步不是完整RAG或独立编码能力的验收。
